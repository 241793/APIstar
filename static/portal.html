三步完成接入

从注册到第一个成功调用，不超过五分钟

1

注册并创建密钥

登录控制台后在「我的密钥」一键创建专属 API Key。

# 控制台操作
我的密钥 → 创建密钥
2

浏览接口文档

接口广场查看每个接口的参数定义与响应示例。

# 文档齐全
参数表 / curl 示例 / 在线调试
3

发起真实调用

请求头携带密钥，向网关发起真实请求。

curl "{host}/svc/weather?city=上海" \
  -H "Authorization: Bearer sk-****"
